# Require Root-child parallelism and keep children as leaves

Diverter will implicitly delegate when at least one bounded Child Lane can run while the Root Session continues a distinct, useful Root Lane; a second child lane is not required, but specialist offloading with no Root Lane does not qualify implicitly. It defaults to the Smallest Sufficient Lineup, a focused skill may own the Root Lane while Diverter supplies a non-duplicative Supporting Child, and every Diverter-dispatched child remains a leaf so the Root Session alone owns decomposition, follow-up routing, integration, verification, and the final user outcome. Diverter constrains those outcomes without prescribing a closed action checklist, preserving task-appropriate Root autonomy while replacing v0.3.2's practical dependence on multiple delegable child lanes and avoiding duplicate investigation or uncontrolled nested orchestration.
