# Use Codex hooks for Advisory Gate Activation

Cast Subagents will be distributed exclusively as a single-repository Codex plugin and will deliver Advisory Gate Activation through the Codex `SessionStart` lifecycle hook. The repository will contain its own marketplace entry, which points back to the repository URL, so the repository remains both the plugin source and its marketplace rather than adopting a nested multi-plugin layout. The plugin exposes the existing skill only from `skills/cast-subagents/SKILL.md`; its references move beneath that skill, and the root-level standalone skill entry is removed without a duplicate, symlink, or compatibility shim. The hook injects only the short Advisory Gate: Root Session scope, delegated-subagent bypass, trigger-pattern check, suggestion-before-work rule, and silent non-match behavior. Detailed classification, role selection, work modes, and approval handling remain exclusively in the bundled skill. The hook uses the documented default `hooks/hooks.json` location and a stateless Python 3.11+ command that prints the gate as plain stdout developer context; Python 3.11+ is therefore a required plugin runtime. The previous standalone skill installation and AGENTS.md injection path will be removed without a fallback or migration utility; existing legacy AGENTS.md blocks are outside this change's scope. `.codex/INSTALL.md` remains the only installation entry point. In that single agent-led flow, Codex adds the marketplace, installs the plugin, guides hook trust, locates the installed plugin files, and directly runs the existing role installer for the Selected Role Set. Agent TOML files ship inside the plugin repository and are written only to `${CODEX_HOME:-$HOME/.codex}/agents/` by that script; project-scoped role installation is removed. The user never runs the script manually, and no one-time installation skill is added. The role installer never modifies AGENTS.md or activates the gate. `SessionStart` injects the gate once for `startup`, `resume`, `clear`, and `compact`, avoiding repeated injection during approval replies while keeping the gate present throughout the Root Session. Hook trust, skipped execution, timeout, and failure use Codex's native visible behavior: the session may continue without the Advisory Gate, and Cast Subagents adds no blocking, retry, or fallback path. The first plugin manifest version is `0.1.0`, published as GitHub Release `v0.1.0` after its release checks pass. This makes a hook-capable Codex runtime and explicit hook trust installation requirements, trading compatibility with older or non-Codex hosts for versioned, plugin-native activation that does not modify user instruction files.
